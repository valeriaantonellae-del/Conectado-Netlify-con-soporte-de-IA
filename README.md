# Conectando a Netlify con soporte de IA
## Que se encontrara en este repositorio?
1. Desarrollo de la capa 1 con Claude
   * A partir de una Base de Datos de Excel, solicitamos que genere indicadores en Excel para posteriores estudios.
   * Luego con estos indicadores solicitamos que genere un html para publicar en Netlify

2. Desarrollo de la capa 2 con Netlify
   * Creamos el usuario en Netlify y el proyecto nace con la suba del archivo index.html
   * Hemos cambiado el nombre generado del proyecto por otro mas acorde a la necesidad de la clase.
